# Information Security Guidelines

## Passwords

Use the company password manager for all work accounts. Passwords must be at least 14 characters long. Never reuse a work password on a personal site.

## Two-factor authentication

Two-factor authentication is mandatory for email, the HR portal and the finance portal. Use the authenticator app, not SMS codes.

## Lost devices

Report a lost or stolen laptop or phone to the IT desk within 1 hour by calling extension 4400. IT will lock and wipe the device remotely.

## Phishing

Forward suspicious emails to the security team using the Report button in your mail client, then delete them. Do not click links in unexpected messages that ask for passwords.
